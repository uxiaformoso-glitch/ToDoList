# ToDoList

## Lista de requisitos para el javaScript
- Se deben poder crear y añadir nuevas tareas  
- Se deben poder eliminar todas las tareas indivudualmente + todas las tareas de golpe(con el botón de abajo del contenedor)  
- Las tareas deben guardarse en el local storage  
  
- Las tareas deben tener un nombre y un estado (Pendientes || Completadas)   

### Botones
- El botón de "Añadir" debe añadir nuevas tareas  
- El botón "Eliminar todas las tareas" debe eliminar todas las tareas  
- Los botones "Todas", "Pendientes" y "Completadas" deben marcar en ese mismo orden: todas las tareas existentes, solo las tareas con estado pendiente y solo las tareas completadas.  
- Las tareas deben tener un checkmark para marcarlas como completadas
